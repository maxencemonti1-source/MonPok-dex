# MonPok-dex
MonPokédex est une plateforme pour les collectionneurs de cartes Pokémon. Les utilisateurs peuvent acheter des packs à différents prix et découvrir la carte obtenue au hasard. Ils peuvent ensuite l'ajouter à leur collection, demander sa livraison à domicile, la revendre sur la plateforme ou l'échanger avec un autre utilisateur dans l'espace dédié.
